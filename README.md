# AI Job Agent

AI 기반 채용공고 수집 및 분석 프로그램입니다.

## 주요 기능

- 채용공고 자동 수집
- SQLite를 이용한 공고 저장 및 중복 방지
- Ollama + Qwen 로컬 LLM을 이용한 채용공고 분석
- Streamlit 기반 채용공고 대시보드
- 채용공고 검색 및 필터링

## 사용 기술

- Python
- Playwright
- BeautifulSoup
- SQLite
- Ollama
- Qwen
- Streamlit

## 개발 예정 기능

- 실제 채용정보 API 연동
- 기계공학 전공자에게 적합한 공고 자동 분류
- AI 기반 직무 적합도 분석
- Telegram 신규 채용공고 알림
- 개인 취업 Agent 기능
